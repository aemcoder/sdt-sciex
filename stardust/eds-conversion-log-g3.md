## 5. Decisions / justifications (beyond § 3)

- **Stories topic tabs** — G1's `section-tabs` mechanism reused verbatim: 13 label rows + 13 following sections carrying section-metadata `tab | <Topic>`, each holding ONE `cards media grid` block (3-up from 768, gap 32 × 48). The prototype pairs every panel's grid with the same `.media-card` XF markup, so the block variant is identical across panels; `section-tabs ruled` only adds the live top rule to the reabsorbed h2 head. qa-gate reports the 12 inactive-panel grids as "renders non-empty" FAILs (display:none at t=0 — the G1 software precedent); `drive.mjs` activates each of the 13 panels and asserts its grid renders (2 / 2 / 4 / 6 / 13 / 14 / 5 / 5 / 5 / 11 / 12 / 13 / 16 cards, 3 columns, 416 px media).

- **page-content chrome** — metadata `Template: page-content` + `Footer: /footer-legacy` (KB/G4 mechanism; `/footer-legacy` already authored, must be on the publish roster).
