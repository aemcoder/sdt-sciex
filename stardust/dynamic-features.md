# Dynamic features — sciex.com (replica → AEM Edge Delivery)

**Shape of the source.** sciex.com is three front ends behind one host:
1. **sciex-v3** — AEM Sites, Tailwind + Alpine.js + Splide (≈55/73 pages: home, applications, products, technology, about-us). Header/footer are an experience fragment with Coveo headless search, an account dropdown, "Request a quote", Shop, and a 4-language footer switcher.
2. **SCIEX Now legacy** — AEM Sites, Bootstrap + Magnific Popup + hCaptcha + TinyMCE (15/73: `/support`, `/support/request-support`, KB articles, spectral-library, whitepapers, …). Own header (`u-header--search` GET form).
3. **Edge Delivery already** — 3/73 crawled pages are served by an EDS code base on sciex.com itself (`/scripts/aem.js`, `/blocks/*`, `nav.plain.html`, `footer.plain.html`, `placeholders.json`, `hreflang.json`): `/about-us/contact-us`, `/support/customer-documents` (→ `/search-results`), `/support/knowledge-base-articles` (the "resource hub"). Their block code is publicly served from `https://sciex.com/blocks/<name>/<name>.js` and is the owner's own code — the replica can port it rather than reverse-engineer it.

Every first-party API path probed on the target is **host-bound** (404): `/bin/sciex/currentuserdetails`, `/libs/granite/csrf/token.json`, `/placeholders.json`, `/hreflang.json`, `/search-results`, `/nav.plain.html`, `/footer.plain.html`, `/resource-hub`, `/kr/`.

## Listings contract

No index-driven listing block exists on the 73 crawled pages: card rails ("Newest products", "Thought leaders", categories, three-card, media-grid) are authored rows. Search is the only index consumer.

| content type | `<meta name>` each page must emit | index / consumer |
|---|---|---|
| all pages | `title`, `description`, `template` (generic-page-template · kb-article · support-legacy · landing-v3), `pagetrackingid` (e.g. `GEN-MKT-18-7897-A`, `RUO-MKT-18-11840-A`), `content-type` (Applications · Knowledge base articles · Products and services · Regulatory documents · SCIEX How · Technical notes · Training · User guides · eCommerce) | `query-index.json` → interim results page S-02 (facet `contentType`) |
| KB article | `content-type: Knowledge base articles`, `kb-id` (slug `_en_us` suffix), `published-time`, `modified-time`, `locale` | query index (S-02 / S-03 interim) |
| localized page | `locale` (en-US · ko-KR), `hreflang` alternates from D-02 sheet | I18N-01 |
