Answer

If a hardware profile won't activate when a Selexion® Differential Mobility Spectrometer (DMS) is added, check to see that the root directory in Analyst® software is set to the Analyst Data folder. If other directories are used for the root, the software will not be able to access the API Instrument folder settings needed to run the Selexion device. Resetting the root directory to the Analyst Data folder should restore Selexion functionality and allow the hardware profile to activate in Analyst software.
